# SkerryKV v0.2.1 — first MVP release

SkerryKV is a native Rust service for immutable, BLAKE3-addressed binary objects.
This first release includes the HTTP API, terminal dashboard, MCP adapter,
durable deletion, scheduled garbage collection, and offline vacuum.

## Downloads

Native archives are provided for Linux x86-64 and ARM64, Windows x86-64, and
macOS Intel and Apple Silicon. Each archive contains the `skerry` executable,
example configuration, documentation, license, and build provenance. Verify
downloads with `SHA256SUMS` or the archive's `.sha256` sidecar.

Linux binaries are built and tested on Ubuntu 24.04 (GNU/glibc 2.39); macOS
binaries on macOS 15; Windows on Windows Server 2022. macOS packages are not
Apple notarized. These are native builds, not universal macOS binaries.

## Storage and upgrade

New stores use storage format v2. Existing v1 stores remain usable but need an
explicit offline upgrade for deletion and maintenance. Back up the complete
store, stop its service, then run `skerry upgrade --path STORE`. Older binaries
reject v2 stores; downgrading the executable does not downgrade the data.

Deletion is by hash through CLI/HTTP and requires the service administrator
token. Scheduled GC is opt-in. Vacuum is offline and supports a nonmutating
dry run. MCP scoped credentials cannot delete objects.

## MVP limits

- One storage volume; no replication or remote storage adapters.
- GC is bounded by a copy budget and currently copies whole source segments.
- Full journal replay is required at startup; vacuum checkpoints its history.
- The v2 durability barriers reduce write throughput compared with v0.1.
- Process-crash tests do not establish hardware power-loss safety.

for operation, recovery, installation, and verification instructions.
